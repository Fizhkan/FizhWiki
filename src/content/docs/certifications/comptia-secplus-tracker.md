Pelacak persiapan menghadapi sertifikasi dasar keamanan sistem **CompTIA Security+ (SY0-701)**.

---

## 🎯 Domain 1: General Security Concepts (12%)
- [x] CIA Triad (Confidentiality, Integrity, Availability)
- [x] Konsep Non-repudiation dan AAA framework
- [x] Prinsip Zero Trust Architecture (ZTA)
- [ ] Pengenalan kriptografi simetris vs asimetris
- [ ] Public Key Infrastructure (PKI) & sertifikat digital X.509

---

## ⚠️ Domain 2: Threats, Vulnerabilities, and Mitigations (22%)
- [x] Vektor serangan Malware (Ransomware, Trojan, Spyware)
- [x] Social Engineering (Phishing, Spear Phishing, Vishing, Whaling)
- [x] Serangan jaringan: Man-in-the-Middle (MITM), ARP Poisoning, DNS Spoofing
- [x] DoS/DDoS (SYN flood, DNS Amplification)
- [ ] Vulnerability scanning vs Penetration testing

---

## 🏗️ Domain 3: Security Architecture (18%)
- [x] Segmentasi jaringan: VLAN, DMZ, Air-gapping
- [x] Firewall types: Packet filtering, Stateful, Next-Gen Firewall (NGFW)
- [ ] Intrusion Detection System (IDS) vs Intrusion Prevention System (IPS)
- [ ] Virtual Private Network (VPN): IPsec vs OpenVPN/WireGuard

---

## ⚙️ Domain 4: Security Operations (28%)
- [x] Analisis log jaringan (Wireshark, syslog, journalctl)
- [ ] Baseline monitoring dan deteksi anomali
- [ ] Incident Response lifecycle (Preparation, Identification, Containment, Eradication, Recovery, Lessons Learned)
- [ ] Backup strategies (3-2-1 rule)

---

## 📜 Domain 5: Security Program Management & Oversight (20%)
- [ ] Risk Management & Assessment (Quantitative vs Qualitative)
- [ ] Keamanan rantai pasok (Supply chain risk)
- [ ] Regulasi kepatuhan privasi (GDPR, ISO 27001, NIST CSF)
